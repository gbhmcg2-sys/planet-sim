행성 충돌 시뮬레이션 — 설치형 앱(PWA) 패키지
================================================

들어 있는 파일
  index.html              앱 본체
  three.min.js            3D 엔진 (Three.js r128, MIT 라이선스)
  manifest.webmanifest    앱 이름·아이콘·화면 설정
  sw.js                   오프라인에서도 열리게 하는 파일
  icons/                  앱 아이콘 4종

1. 인터넷에 올리기 (https 주소가 꼭 필요합니다)
  이 폴더 전체를 그대로 올리면 됩니다. 파일 이름과 폴더 구조는 바꾸지 마세요.
  - Netlify: 로그인 후 "Add new site > Deploy manually"에 이 폴더를 끌어다 놓기
  - GitHub Pages: 저장소에 이 폴더의 파일을 올리고 Settings > Pages에서 켜기
  - Cloudflare Pages: "Upload assets"로 이 폴더 올리기
  세 곳 모두 무료 요금제가 있고 https 주소가 자동으로 생깁니다.
  (서비스 화면과 메뉴 이름은 바뀔 수 있습니다.)

2. 휴대폰·PC에 설치하기
  링크를 누르면 먼저 브라우저에서 열립니다(자동으로 설치되지는 않습니다).
  화면 위쪽의 주황색 "앱 설치" 버튼을 누르거나, 아래 방법으로 설치합니다.
  올린 주소를 브라우저로 연 뒤
  - 안드로이드 크롬: 메뉴(점 세 개) > "앱 설치" 또는 "홈 화면에 추가"
  - 아이폰 사파리: 공유 버튼 > "홈 화면에 추가"
  - PC 크롬·엣지: 주소창 오른쪽의 설치 아이콘
  한 번 연 뒤에는 인터넷이 없어도 실행됩니다. (글꼴만 기기 기본 글꼴로 보입니다.)

3. 수정해서 다시 올릴 때
  sw.js 맨 위의 VERSION 값을 바꾼 뒤 올려 주세요.
  바꾸지 않으면 이미 설치한 사람에게는 예전 버전이 계속 보입니다.

4. 참고
  - 파일을 더블클릭해서 열면(file://) 시뮬레이션은 되지만 "설치"와 오프라인 저장은 동작하지 않습니다.
  - 미션 도장은 각 기기의 브라우저에 저장됩니다.
  - 구글 플레이에 올리려면 이 주소를 PWABuilder(pwabuilder.com) 같은 도구로 안드로이드 앱으로 포장할 수 있습니다.
